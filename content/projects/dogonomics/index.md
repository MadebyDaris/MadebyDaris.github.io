## Overview

**Dogonomics** is a financial assistant and automated trading system (ATS) currently in development. The project aims to integrate AI and machine learning techniques to process financial data and assist with automated trading strategies.

## Development Logs

*   **Initial Conception:** The project started as a basic bot for handling finance-related tasks and executing automated trading rules.
*   **August 2025 Updates:** Continued development on the financial assistant core, structuring the app to handle real-time data ingestion and basic machine learning forecasting models.
